# A股情绪作战台（market-desk）

本地运行的 A 股短线情绪与主线作战台：跟**实时主线**给 ETF / 主板回踩票的买卖参考，并支持本地仓位记账与卖出提示。

> 数据来自东财、腾讯公开行情接口，仅供学习与辅助观察，**不会下单**，不构成投资建议。

## 主要功能

| 模块 | 作用 |
|------|------|
| 实时主线结论 | 识别当日主线板块，给出观望 / 观察回踩 / 可买入 |
| 观察支线 | 同池第二名且分差不大时展示，只盯回踩，永不 ready |
| 推荐买入 | ETF 主推 + 主板个股备选，带建议买 / 回踩 / 止损 / 不追价 |
| 仓位建议卖出 | 对着本地记账持仓给止损、止盈、减仓、继续持有 |
| 大盘相位 | 恐慌 / 分歧 / 发酵 / 高潮 + 温度（0–100） |
| 周期位置 | 相对最近一次「高潮」的 D-1…D+N，可点击回看日级摘要 |
| 竞价基调 | 9:25 开盘涨幅中位与高开占比，锁日后不变 |
| 热点 / 冰点 / 置顶板块 | 东财行业+概念卡，含龙头、周期标签、聚集度 |
| 异动观察池 | 涨停 / 炸板 / 跌停 / 高换手，非买点 |
| 仓位记账 | 本地 SQLite：代码、买价、股数；汇总突出当日盈亏，浮盈次要 |
| 信号复盘 | 按交易日浏览可买/建议卖信号，隔日打分看命中率与次日/三日涨跌；个股可看股东户数/增减%/户均市值（季度） |
| 早决策摘要 | 盘前规则汇总：相位、竞价、主线、相似日、仓位与执行清单（可复制，不推送） |
| 点票看图 | 点击名称打开分时/日线（含 MA5/MA20），并可跳转雪球 `xueqiu.com/S/SH600519` |
| 盘中分段 | 竞价 / 开盘半小时 / 午前 / 午后分段结论，开盘与午后更谨慎 |
| 主线切换 | 主线板块名字变化时记时间线，作战页可回看 |
| 主线生命周期 | 板块页顶三栏：萌芽 / 主升 / 衰退（多日热点持续度） |
| 主要指数 | 大盘页顶部：上证 / 深成 / 创业板 / 科创50 / 沪深300 / 中证500 / 上证50 |

**界面**：顶栏页签 — 作战 / 大盘 / 板块 / 观察 / 仓位 / 复盘（记住上次所选）。

**交易口径**

- 个股只做**主板**（排除 300/301 创业板、688 科创板等）
- 创业板 / 科创**个股不推荐买**；对应 **创业板 ETF（159915）、科创50 ETF（588000）可以买**
- 个股总市值默认 **≥120 亿** 才进推荐（参数可改；设 0 关闭；已存设置不会自动改写）

## 详细算法

### 1. 市场温度（0–100）

对主板广度与涨停结构加权（上限截断后相加），再按量能/指数/大面软调节：

| 因子 | 权重 | 归一 |
|------|------|------|
| 涨停家数 | 25 | /80 |
| 总晋级率 | 14 | /50 |
| 晋级 1→2 / 2→3 | 4 + 4 | /55、/45（有样本时） |
| 高度（最高连板） | 16 | /8 |
| 梯队完整度 | 3 | /100；断层另 −4 |
| 上涨广度 | 14 | /100 |
| 昨停溢价中位 | 10 | /8（负溢价软扣分） |
| 炸板率（反向） | 8 | 1 − zb%/100 |
| 跌停家数（反向） | 7 | 1 − dt/40 |

软调节：成交额分位 &lt;30 −6 / ≥70 +3；指数偏弱 −5 / 偏强 +2；大面≥80/120 再减；涨停均炸板次数高 / 晚封占比高再减。

相位补充：2→3 晋级≥35% 可支撑高潮；梯队断层可挡假高潮/倾向分歧。昨停溢价≤−1% 时作战「可买入」降观察回踩。

### 2. 大盘相位

按优先级判定：

1. **恐慌**：跌停 ≥ 40，或温度 &lt; 恐慌阈值（默认 28），或（涨停 ≤ 8 且跌停 ≥ 15）；或大面≥120 且温度&lt;(恐慌+12)；或指数偏弱且跌停≥25
2. **高潮**：高度 ≥ 6 且（总晋级 ≥ 28% 或 2→3≥35%）且涨停 ≥ 35；或温度 ≥ 高潮阈值（默认 72）且高度 ≥ 5 —— **若缩量、指数偏弱或梯队断层则降级为发酵/分歧**
3. **分歧**：炸板率 ≥ 48%，或（涨停 &lt; 18 且晋级 &lt; 12%）；或高度≥5 且梯队断层且总晋级&lt;22%
4. **发酵**：温度 ≥ 发酵阈值（默认 45）
5. 其余 → **分歧**

温度阈值可在「参数」面板调整（`phase_panic_temp` / `phase_ferment_temp` / `phase_climax_temp`）。

### 3. 板块状态

对热点行业/概念卡：

| 状态 | 条件 |
|------|------|
| 尖峰禁追 | 龙头连板 ≥ 3，或板块涨幅 ≥ 4.5% |
| 确认中 | 涨幅 ≥ 1.5% 且卡内主板涨停 ≥ 2 |
| 退潮 | 板块涨幅 &lt; 0 |
| 观察 | 其余 |

冰点行业另算：传染预警 / 冰点 / 冷冻 / 相对最冷（只观察，不当买点）。

### 4. 实时主线打分

优先在**行业**卡中取最高分（无行业则用全部热点卡）：

```
得分 = 状态分 + 涨停×6 + 涨幅 + 聚焦×0.15 + min(热度天数,6)×3
     + 梯队加减 + ETF映射加减 + 龙头结构加减 − 炸板/开板/晚封
```

状态分：确认中 +50（涨停&lt;3 时 +36），尖峰 +28，观察 +12，退潮 −25。精确 ETF 映射 +5，无映射 −3。

**龙头结构加分**（认主题，不奖高度）：1–2 板总龙头且有卡位龙 / 二板≥2 / 涨停≥3 → +4；二板龙+跟风再 +2；主板龙再 +1.5。尖峰或龙头≥3 板 → **不加**。

**Sticky**：挑战者须高出约 12 分；持有期内（默认 5 分钟）×1.5；同主题（煤炭↔动力煤）×2 且默认不记时间线切换；**衰退/退潮 sticky 换防门槛×0.55，且不再叠同主题×2**；挑战者有精确 ETF 而现主线没有时门槛 ×0.75。作战台「主线为什么是它」展示分差与原因。

主线名称按关键词映射到 ETF（见 `config.MAINLINE_ETF_RULES`）。**无精确映射时软匹配近似 ETF：只观察回踩、不标 `etf_mapped`、个股仍走 orphan 严过滤；仍无映射则不做载体买入定价。**

**观察支线**：同池第二名、非退潮、非同主题、且与主线分差 ≤ `side_mainline_gap`（默认 12，设 0 关闭）时展示。只走观察回踩定价，永不 ready。

### 5. 结论动作（观望 / 观察回踩 / 可买入）

| 动作 | 主要条件 |
|------|----------|
| 观望 | 无主线；9:15–9:30 竞价；主线已退潮；相位恐慌禁开仓 |
| 观察回踩 | 主线尖峰；生命周期偏衰退；无 ETF 映射；**软 ETF 近似映射**；结构未确认；**指数偏弱 / 成长风格弱 / 缩量 / 大面 / 弱竞价** 闸门降级 |
| 可买入 | 主线确认中；或载体离日低回升 ≥ 0.35% 且未继续下探，且通过上述闸门（须精确 ETF 映射） |

另：当前相位历史命中率（复盘，n≥5）&lt;35% → 禁个股、提示仅 ETF 小仓，并将「可买入」降为观察回踩；&lt;45% → 偏小仓。相似日偏降温（n≥2）可将「可买入」降为观察回踩。

推荐卡片顺序：**先回踩到位 arm**，再做**分时确认**（优先东财均价线）：贴尖 / 抬高点 / 不站均价 / 回踩不缩量 → ready 关掉、改盯回踩；样本不足标「分时未验」不关 ready。软/无映射 ETF 即使到位也**不会**升「可买入」。

复盘命中率默认只统计**已交易**信号（`hit_rate_mode=traded`），运行参数或复盘工具栏可切「全部已打分」。观察回踩时只落库**到位/ready**买入卡，避免盯回踩清单刷屏。

离日高现买门槛：ETF ≥ 约 0.40%、个股 ≥ 约 0.75%；个股日高回撤 ready 需 ≥ 1.0%（无精确 ETF 时 ≥ 1.2%）。回踩建议价约现价下 ETF 0.45% / 个股 0.85%（或日低中位）。

薄确认主线（确认中且涨停≤2）：个股现买须跨板块≥2 **或**同主题≥1。

复盘闸门归因累计同日 `confirm_fail_hist`；假杀仅计终态仍未 ready 的信号。卖点闭环按 ETF / 个股分桶（n≥10）微调止盈回撤。

### 6. 推荐买入价

**ETF（优先）**

- 可买且未贴日高：建议买 ≈ 现价
- 过热 / 观察回踩：建议买改用回踩价
- 回踩价 ≈ min(现价×0.9935, (日低+现价)/2)，且不低于日低
- 止损 ≈ 日低（无日低则现价×0.985）
- 不追 ≈ 日高（无则现价×1.012）
- **确认**：离日高足够远（ETF≈0.40%、股≈0.80%），否则 ready 降为盯回踩；涨幅偏强但成交额过弱也降级

**主板个股备选**

- 排除：涨停、炸板池、连板≥2、ST、创业/科创、总龙头/卡位龙、换手≥25%
- 偏好：涨幅约 0–5.5%，高点回撤约 1.2–4.5%；换手 15%+ 不做现买
- **跨板块共振**：候选仍只来自当前主线成分；若同代码还在其它热点卡中，每多一块 +2，同主题再 +3，该块为「确认中」再 +2（合计封顶 +12）
- **日线趋势分**：上升 +8、下降 −8、震荡/取不到不加不减；取到后按新分重排个股卡
- 主线名含「创业板」「科创」时**不给个股**，只给对应 ETF
- **确认**：不得明显弱于主线 ETF；指数偏弱不做现买；离日高过近改回踩；分时未确认（含量能未缩）改回踩
- **日线趋势**：确认上升才标注并放行现买；取不到/样本不足不显示、不因此关 ready；明确非上升静默关 ready（卡片不展示「非上升」文案）

### 7. 仓位建议卖出

对本地记账持仓（最多展示 4 条），优先级：

1. **T+1**：`last_buy_date` 为当日 → 不亮现卖（含止损提示也只锁定），复盘不可记卖出
2. **止损卖出**：现价 ≤ 止损带，或浮盈 ≤ pnl_stop——对所有仓位；**站上 MA20 且日线非下降**时可先减一半（软止损）
3. **冲高回落 / 结构回撤**：浮盈 ≥ take 且高点回撤达标（更深回撤标结构减仓）；回撤锚持仓峰值
4. **落袋为安**：浮盈 ≥ pocket
5. **建议减仓**：相位恐慌或高潮可对全仓软减；主线退潮/观望/衰退只减**属于当前主线**的仓（载体/成分池）；个股且主线载体走弱时同理
6. **继续持有**：建议卖 = 目标价（成本 +3%/+5%，或贴近日高）

止损参考：成本×0.985（ETF）/0.97（股）；若日低低于成本，再与日低取合理下沿。卖点闭环（ETF/个股分桶）可微调 pb/pocket。总仓触相位上限时关 ready；账户资金仍为默认 5 万时会提示改真实资金。

### 8. 异动观察池（非买点）

去重后最多 24 只：

1. 涨停池按连板取前 12  
2. 炸板前 8  
3. 主板跌停前 6  
4. 换手 ≥ 15% 且未入选者，按换手前 6  

标签：连板 ≥ 2 或涨幅 ≥ 7% → **禁追**；其余 → **观察**。

### 9. 周期位置（EOD）

在日级库中找最近相位 =「高潮」的交易日，今天相对该日的偏移为 D+N。  
可点击有数据的节点查看当日涨停/跌停/晋级/炸板等摘要；点「今」回到实时事件。

### 9b. 大盘波浪情景（观察）

大盘页对**上证指数**做艾略特波浪多假设：上升推动 1–5、调整 A/B/C、下跌推动 1–5、三角/复合。  
每条给契合度、后市路径、否决位；**不改**作战台买卖结论。日线约 120 根按交易日缓存。

### 10. 竞价基调

用主板开盘涨幅：中位数与「高开 ≥ 3%」占比。  
约 9:25 后锁定当日，不再改写。  
弱竞价（中位 ≤ −0.5%）会压仓位提示；≤ −1.2% 可将「可买入」降为观察回踩。

### 10b. 集合竞价策略页（独立 Tab）

导航「竞价」：昨停名单开盘型分档（双确认 / 顶级抢筹优先 / 次级可排单）。  
与作战台买卖**完全隔离**——「抢筹」不会改顶栏可买入 / ready。可钉自选。封成比依赖涨停池封单字段，无则显示 —。

### 11. 相似日对照

在近端日级快照中找同相位、温度接近、涨停接近的交易日，汇总次日温度/涨停均值。降温日明显多于升温且样本 ≥ 2 时，作为真实闸门把「可买入」降为观察回踩；升温仅加强防追提示。

### 12. 主线生命周期

萌芽 / 主升 / 衰退；涨停衰减与斜率转负可提前判衰退。复盘命中率偏低时衰退更敏感。当前主线若判衰退，作战结论降为观察回踩。主升描述扩散强度，不等于可买入。

## 说明

- 仓位与日级快照仅存本机 `data/desk.db`
- 重点变化（可买入、卖出建议、主线切换、相位恐慌/高潮）会打 **Windows 右下角通知**；`config.TOAST_ENABLED` 可关，同键约 180 秒冷却
- 公开行情可能延迟或限流；盘中刷新过快有被封风险，可按需改 `SESSION_REFRESH_SECONDS`
- 界面术语旁的 `?` 会弹出含义与近似算法（见 `glossary.py`）
