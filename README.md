# A股情绪作战台（market-desk）

本地运行的 A 股短线情绪与主线作战台：跟**实时主线**给 ETF / 主板回踩票的买卖参考，并支持本地仓位记账与卖出提示。

> 数据来自东财、腾讯公开行情接口，仅供学习与辅助观察，**不会下单**，不构成投资建议。

## 主要功能

| 模块 | 作用 |
|------|------|
| 实时主线结论 | 识别当日主线板块，给出观望 / 观察回踩 / 可买入 |
| 推荐买入 | ETF 主推 + 主板个股备选，带建议买 / 回踩 / 止损 / 不追价 |
| 仓位建议卖出 | 对着本地记账持仓给止损、止盈、减仓、继续持有 |
| 大盘相位 | 恐慌 / 分歧 / 发酵 / 高潮 + 温度（0–100） |
| 周期位置 | 相对最近一次「高潮」的 D-1…D+N，可点击回看日级摘要 |
| 竞价基调 | 9:25 开盘涨幅中位与高开占比，锁日后不变 |
| 热点 / 冰点 / 置顶板块 | 东财行业+概念卡，含龙头、周期标签、聚集度 |
| 异动观察池 | 涨停 / 炸板 / 跌停 / 高换手，非买点 |
| 仓位记账 | 本地 SQLite：代码、买价、股数；现价与浮盈随刷新更新 |

**交易口径**

- 个股只做**主板**（排除 300/301 创业板、688 科创板等）
- 创业板 / 科创**个股不推荐买**；对应 **创业板 ETF（159915）、科创50 ETF（588000）可以买**

## 详细算法

### 1. 市场温度（0–100）

对主板广度与涨停结构加权（上限截断后相加）：

| 因子 | 权重 | 归一 |
|------|------|------|
| 涨停家数 | 25 | /80 |
| 晋级率 | 18 | /50 |
| 高度（最高连板） | 18 | /8 |
| 上涨广度 | 14 | /100 |
| 昨停溢价中位 | 10 | /8（负溢价按 0） |
| 炸板率（反向） | 8 | 1 − zb%/100 |
| 跌停家数（反向） | 7 | 1 − dt/40 |

### 2. 大盘相位

按优先级判定：

1. **恐慌**：跌停 ≥ 40，或温度 &lt; 28，或（涨停 ≤ 8 且跌停 ≥ 15）
2. **高潮**：高度 ≥ 6 且晋级 ≥ 28% 且涨停 ≥ 35；或温度 ≥ 72 且高度 ≥ 5
3. **分歧**：炸板率 ≥ 48%，或（涨停 &lt; 18 且晋级 &lt; 12%）
4. **发酵**：温度 ≥ 45
5. 其余 → **分歧**

### 3. 板块状态

对热点行业/概念卡：

| 状态 | 条件 |
|------|------|
| 尖峰禁追 | 龙头连板 ≥ 3，或板块涨幅 ≥ 4.5% |
| 确认中 | 涨幅 ≥ 1.5% 且卡内主板涨停 ≥ 2 |
| 退潮 | 板块涨幅 &lt; 0 |
| 观察 | 其余 |

冰点行业另算：传染预警 / 冰点 / 冷冻 / 相对最冷（只观察，不当买点）。

### 4. 实时主线打分

优先在**行业**卡中取最高分（无行业则用全部热点卡）：

```
得分 = 状态分 + 涨停只数×5 + 板块涨幅 + 聚焦×0.15
```

状态分：确认中 +50，尖峰禁追 +28，观察 +12，退潮 −25。

主线名称按关键词映射到 ETF（通信→515050、半导体→512480、AI/算力→159819、创业板→159915、科创→588000 等，见 `config.MAINLINE_ETF_RULES`）。

### 5. 结论动作（观望 / 观察回踩 / 可买入）

| 动作 | 主要条件 |
|------|----------|
| 观望 | 无主线；9:15–9:30 竞价；或主线已退潮 |
| 观察回踩 | 主线尖峰禁追；或结构未完全确认 |
| 可买入 | 主线确认中；或载体离日低回升 ≥ 0.35% 且价格未继续下探，状态为确认中/观察 |

### 6. 推荐买入价

**ETF（优先）**

- 可买且未贴日高：建议买 ≈ 现价
- 过热 / 观察回踩：建议买改用回踩价
- 回踩价 ≈ min(现价×0.996, (日低+现价)/2)，且不低于日低
- 止损 ≈ 日低（无日低则现价×0.985）
- 不追 ≈ 日高（无则现价×1.012）

**主板个股备选**

- 排除：涨停、连板≥2、ST、创业/科创、总龙头/卡位龙
- 偏好：涨幅约 0–5.5%，高点回撤约 0.8–4%
- 主线名含「创业板」「科创」时**不给个股**，只给对应 ETF
- 近高点不追现价，改为回踩价

### 7. 仓位建议卖出

对本地记账持仓（最多展示 4 条），优先级：

1. **止损卖出**：现价 ≤ 止损带，或浮盈 ≤ −1.5%（ETF）/ −3%（股）
2. **冲高回落止盈**：浮盈 ≥ 3%/5% 且高点回撤 ≥ 0.8%/1.5%
3. **落袋为安**：浮盈 ≥ 5%/8%
4. **建议减仓**：结论观望 / 主线退潮 / 相位恐慌或高潮，且仍有浮盈
5. **继续持有**：建议卖 = 目标价（成本 +3%/+5%，或贴近日高）

止损参考：成本×0.985（ETF）/0.97（股）；若日低低于成本，再与日低取合理下沿。

### 8. 异动观察池（非买点）

去重后最多 24 只：

1. 涨停池按连板取前 12  
2. 炸板前 8  
3. 主板跌停前 6  
4. 换手 ≥ 15% 且未入选者，按换手前 6  

标签：连板 ≥ 2 或涨幅 ≥ 7% → **禁追**；其余 → **观察**。

### 9. 周期位置（EOD）

在日级库中找最近相位 =「高潮」的交易日，今天相对该日的偏移为 D+N。  
可点击有数据的节点查看当日涨停/跌停/晋级/炸板等摘要；点「今」回到实时事件。

### 10. 竞价基调

用主板开盘涨幅：中位数与「高开 ≥ 3%」占比。  
约 9:25 后锁定当日，不再改写。

## 说明

- 仓位与日级快照仅存本机 `data/desk.db`
- 重点变化（可买入、卖出建议、主线切换、相位恐慌/高潮）会打 **Windows 右下角通知**；`config.TOAST_ENABLED` 可关，同键约 180 秒冷却
- 公开行情可能延迟或限流；盘中刷新过快有被封风险，可按需改 `SESSION_REFRESH_SECONDS`
- 界面术语旁的 `?` 会弹出含义与近似算法（见 `glossary.py`）
